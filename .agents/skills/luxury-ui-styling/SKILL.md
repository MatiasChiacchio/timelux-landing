# Timelux UI Styling (Warm Luxury & High Perfumery)

## Paleta de Colores Oficial
- **Lienzo / Fondo:** `#fffff4` (amarillo claro / marfil suave).
- **Rojo Principal (Acento / CTA):** `#c40a0a` (botones principales, llamada a la accion y hover).
- **Celeste Pastel (Detalles / Insignias):** `#a6caeb` (badges olfativas, bordes sutiles y chips de categoria).
- **Texto Principal:** `#141416` para lectura sobre fondo claro; `#fffff4` sobre rojo.
- **Texto Secundario:** `#5e626e` para notas de salida, corazón y fondo.

## Reglas de Componentes
1. **Tarjetas de Producto:**
   - Fondo blanco o marfil: `bg-white/90 border border-[#a6caeb]/30 rounded-2xl p-5 shadow-sm hover:shadow-xl hover:border-[#c40a0a]/40 transition-all duration-300`.
2. **Botón Principal de Conversión (WhatsApp):**
   - Estilo: `bg-[#c40a0a] text-[#fffff4] hover:bg-[#a30808] px-5 py-2.5 rounded-full font-medium transition-colors duration-200 inline-flex items-center gap-2`.
3. **Insignias y Filtros de Categoría:**
   - Botón activo: `bg-[#c40a0a] text-[#fffff4]`.
   - Botón inactivo: `bg-[#a6caeb]/20 text-[#141416] hover:bg-[#a6caeb]/40 border border-[#a6caeb]/40`.
   - Tags de notas olfativas: `bg-[#a6caeb]/15 text-[#141416] border border-[#a6caeb]/30 rounded-md px-2 py-0.5 text-xs uppercase tracking-wider`.
